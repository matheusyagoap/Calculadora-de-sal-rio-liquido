# Calculadora de Salário Líquido (Java)

Projeto acadêmico em Java focado em lógica de programação e estruturas de controle (`do-while`, `switch-case` e condicionais). 

O objetivo do programa é simular o cálculo de uma folha de pagamento no terminal, processando descontos de INSS, Imposto de Renda e acréscimo de Salário-Família.

---

### O que o programa faz:

- **Cadastro de dados:** Recebe nome, matrícula, salário bruto e quantidade de dependentes.
- **Regras para dependentes:** Adiciona R$ 67,00 por dependente com idade até 14 anos.
- **Cálculo de deduções:**
  - INSS (8% para salários até R$ 3.000 ou 9% para valores acima).
  - Imposto de Renda (15% para salários acima de R$ 5.000).
- **Demonstrativo final:** Exibe o extrato completo com os descontos e o valor líquido a receber.

---

### Tecnologias e Conceitos

* **Linguagem:** Java
* **Conceitos:** Manipulação do `Scanner`, laços de repetição, regras condicionais e lógica matemática simples.
